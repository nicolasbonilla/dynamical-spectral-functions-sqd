## `src/` — computation & figure scripts (`*.py`)

All scripts live in [`../src/`](../src/) and are run **from the repository root** as `python src/<name>.py`.

### Shared exact-diagonalization engines
| File | Purpose |
|---|---|
| `akw_lanczos.py` | Sector-basis Hubbard engine: sparse ground state + Haydock continued fraction for `A(k,ω)` (PBC). Imported by others. |
| `scaling_lanczos.py` | Haydock/Lanczos scaling engine with explicit sparse H (good to L≈12). |
| `scaling_lanczos_mf.py` | Matrix-free, RAM-staged, **resumable** scaling to L=14 (28 qubits) on a memory-limited box. |

### Spectral / dynamical response
| File | Purpose |
|---|---|
| `sqw_lanczos.py` | Exact dynamical structure factor `S(q,ω)` (density response, N sector). |
| `spin_lanczos.py` | Exact spin structure factor `S^zz(q,ω)` (gapless two-spinon continuum). |
| `sampled_akw.py` | **Sampled-vs-exact `A(k,ω)`** (Fig. 5) — the genuine bitstring-sampled reconstruction. |
| `sqw_field.py` / `recolor_akw_v2.py` | Perceptual "hot" raster fields for the `S(q,ω)` / `A(k,ω)` colormaps (data-faithful). |
| `spectral_validation_max.py` | Max-level validation of the sampled `A(ω)` method (Hubbard L=6, U/t=8). |
| `_maxrigor.py` | Cross-checks: first-moment sum rule, peak dispersion, Haydock convergence. |

### Molecular fermionic-magic suite
| File | Purpose |
|---|---|
| `n19_suite.py` | The nineteen-molecule suite: FCI-verified `F₁`, `\|S\|`, χ — real, self-verified. |
| `n19_spectral.py` | Suite-wide sampled `A(ω)` reconstruction (Contribution #1 across chemistry). |
| `n2_hero_data.py` | N₂ dissociation hero: spectrum + resources move together; `F₁=2Nᵤ` identity. |

### The resource theory (`F₁` vs `\|S\|` decoupling)
| File | Purpose |
|---|---|
| `cost_vs_entanglement.py` | Makes the obstruction empirical: the cost `\|S\|` is governed by entanglement (χ), not `F₁`. |
| `apsg_witness.py` | The **provable witness** (Theorem 2): APSG geminals with `F_k` large yet χ=2, `\|S\|=2^K`. |
| `rigor_floor.py`, `nonfreeness.py` | Supporting rigor: shared-floor/CP-overhead structure; convention-free nonfreeness. |
| `ladder_vs_chain.py` | The chain-vs-2-leg-ladder contrast at matched `F₁` (Fig. 13). |
| `gate1_ladder.py` | Response-targeted determinant selection on the ladder (Plan-B make-or-break). |

### Selector benchmark & scaling
| File | Purpose |
|---|---|
| `headtohead_ms.py` | Multi-seed benchmark (real ED): time-evolution selector vs Krylov vs CIPSI. |
| `scaling_data.py` | Scaling data (L=4,6,8) — `F₁` grows, subspace fraction falls. |

### Hardware, noise, AI
| File | Purpose |
|---|---|
| `molecular_noise_energy.py` | Noise-assisted SQD ground-state energy across the molecular suite (simulated bit-flip + recovery). |
| `molecular_noise_sweep.py` | Same, as a function of the per-qubit bit-flip rate ε. |
| `noise_spectral.py` | Spectral rel-L1 vs bit-flip ε (L=6 Hubbard) for the noise figure. |
| `amortized_recovery.py` | Amortized (train-once) configuration recovery, leave-one-out across a Hubbard family. |

### Figure/table generators (`make_*.py`)
Each emits a native pgfplots fragment or table into `paper/figs/` / `paper/` from a committed `.json`/`.dat`
— **no hand-typed numbers**. One per figure: `make_decoupling_native.py`, `make_resource_master_fig.py`,
`make_method_fig_max.py`, `make_akw_sampled_fig.py`, `make_gallery_native.py`, `make_magic_suite_fig.py`,
`make_hero_fig.py`, `make_bench_fig.py`, `make_scaling_fig.py`, `make_hardware_hero.py`, `make_heron_fig.py`,
`make_noise_fig.py`, `make_noise_recovery_native.py`, `make_gflow_fig.py`, `make_table.py`.

## `notebooks/`
| File | Contents |
|---|---|
| `00_Reproduce_Everything.ipynb` | **Master reproduction** — one narrated, top-to-bottom pipeline regenerating every figure and number: the decoupling identity + witness (`verify.py`), the sampled `A(k,ω)`, the χ–\|S\| resource map, scaling, the 19-molecule magic suite, the selector/noise/AI results, the hardware run, and the figures. | `Spectral_Heron.ipynb` | `A(ω)` on `ibm_fez`: the L=6 Hubbard spectral run (full-sector coverage). Credentials scrubbed. |

The two hardware notebooks have the API **token and instance CRN removed** (placeholders). Insert your own to run.
